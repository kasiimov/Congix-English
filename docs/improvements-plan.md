# План улучшений Congix-English

Цель: сделать курс легче для изучения и интереснее, не перегружая уроки. Каждый пункт — отдельная задача, которую можно делать по одной.

## 1. Список фич и идей

### 1.1 Короткие диалоги вместо сухих примеров
- **Почему:** отдельные фразы вроде "I have a cat" не дают контекста. Диалог в 2-3 реплики даёт ситуацию и ощущение реального языка.
- **Что делать:** в каждом уроке добавить короткий диалог, где используются целевые слова/грамматика. Можно добавить поле `dialogue` в lesson JSON.
- **Формат:** массив реплик `{ speaker, text, translation? }`, 2-4 реплики.

### 1.2 Персонажи и сюжетная нить
- **Почему:** привязанность к персонажу заставляет доходить до конца, а не бросать после нескольких уроков.
- **Что делать:** ввести 2-3 персонажей (например, для Starter — семья/друг, для A1 — ежедневные истории, для A2 — развивающаяся цепочка событий). Каждый блок может быть «главой».
- **Где:** можно хранить краткие «герой-карточки» в docs/characters.md и ссылаться в диалогах.

### 1.3 Аудио / произношение
- **Почему:** слушать — часть обучения; IPA уже задан, но его трудно «услышать» без подсказки.
- **Что делать:**
  - Сделать IPA-транскрипцию кликабельной — показать пояснение звука / сравнение с узбекским.
  - Если возможно — добавить озвучку (TTS или готовые записи) к словам и ключевым фразам.
- **Этап 1 (бюджетно):** пояснительная подсказка к IPA, примеры произношения, разбор сложных звуков.
- **Этап 2 (опционально):** TTS-озвучка через Web Speech API в браузере (низкие издержки, не требует сервера).

### 1.4 Мгновенный фидбек в упражнениях
- **Почему:** сейчас «упражнение» — часто «позапиши/подумай». Мгновенная подсветка правильно/неправильно даёт чувство прогресса без учителя.
- **Что делать:** в `practice_spec` / `exercises` добавить возможность интерактивной проверки:
  - перестановка слов (word order),
  - выбор правильной формы,
  - заполнение пропуска с подсветкой.
- **Где:** это в основном код курса (`course.js` и app.html) — нужно добавить рендеринг интерактивных упражнений.
- **ВАЖНО:** пока 머지 с остальным — сначала доделать недостающие lesson-файлы, потом добавлять интерактив.

### 1.5 Прогресс и геймификация (без перегруза)
- **Уже есть:** `can_do` чеклист и `course_progress` в localStorage.
- **Добавить минимально, но заметно:**
  - бейджи за выполнение блока и уровня,
  - видимый прогресс «сколько can_do выполнено в блоке/уровне»,
  - короткие цели (1-3 урока) с наградой.
- **Где:** app.html / course.js — небольшие UI-улучшения поверх существующего прогресса.

### 1.6 Мини-сессия повторения (спейсд рипити션 «внутри» курса)
- **Почему:** забывается быстро без повторения; `review` уже намекает на это.
- **Что делать:** в начале каждого урока — 3-5 слов/фраз из прошлых уроков уровня с быстрой проверкой.
- **Где:** lesson JSON может содержать `review_session: { items: [...] }` — рендерить в app.html.

### 1.7 «Смыслы» вместо списков слов
- **Что делать:** к каждому слову добавить короткий контекст — ситуацию, где оно полезно, или короткую историю. Con cram — не запоминается, ситуация — да.
- **Где:** в поле `words[].context` или отдельное поле; рендерить внизу карточки слова.

### 1.8 Сделать учебные материалы полнее, но легче по нагрузке
- **Принцип:** один урок — одна can_do поз, одна грамматическая мысль, ~15-20 слов максимум.
- **Почему:** перегрузка убивает мотивацию.
- **Что проверить:** убедиться, что в каждом уроке не слишком много нового сразу.

## 2. Порядок работ (от простого к сложному)

1. **Дописать недостающие lesson-файлы** (Starter + A2) — изначальная цель. Пока файлы не открываются, остальные фичи не имеют смысла.
2. **Добавить диалоги и контекст** к существующим и новым урокам — бюджетно и заметно.
3. **Добавить мини-сессию повторения** (`review_session`).
4. **Сделать IPA-пояснения / кликабельность**.
5. **Добавить интерактивный фидбек** в упражнениях (потом, когда lesson-файлы полны).
6. **Лёгкая геймификация** поверх прогресса.
7. **Сюжетные персонажи** — если захочется.
